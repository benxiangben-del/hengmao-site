# 上海恒猫机电官网产品规范

版本：0.1  
日期：2026-07-17  
状态：业务目标与品牌方向已确认，资料证据待整理

## 1. 产品定义

上海恒猫机电官网是一个面向国内外客户的双语产品展示与产品支持平台。网站首先帮助客户了解、比较和识别产品；购买后继续提供安装方法、使用方法、注意事项及相关视频。

网站不是单纯的企业形象页，也不以在线商城为第一阶段目标。它应同时承担：

1. 产品目录
2. 产品说明书
3. 安装与使用支持中心
4. 企业可信度证明
5. 国内外客户的联系入口

## 2. 业务目标优先级

| 优先级 | 目标 | 用户结果 |
| --- | --- | --- |
| P0 | 展示完整、准确、易查找的产品信息 | 客户能按分类或型号找到产品 |
| P0 | 提供安装、使用和安全注意事项 | 已购客户能自行完成正确安装和基本使用 |
| P0 | 支持中文和英文 | 国内与海外用户获得等价信息 |
| P1 | 建立供应商可信度 | 采购客户能查看企业、工厂、证书、专利和案例 |
| P1 | 形成联系与询盘入口 | 客户可携带明确产品型号联系销售或售后 |
| P2 | 支持资料下载与经销传播 | 说明书、参数表和视频链接可以稳定分享 |

## 3. 核心受众

### A. 个人消费者

典型需求：

- 根据包装或铭牌上的型号找到产品
- 查看组装和安装视频
- 了解首次使用步骤
- 查找安全注意事项、常见问题和维护方式
- 找到适配的水枪、高压管或其他配件

设计要求：移动端优先、型号搜索突出、步骤简单、视频清晰、少用行业术语。

### B. 国内工业采购客户

典型需求：

- 快速比较型号、参数、适用场景和配套能力
- 核验工厂、证书、专利、生产能力和案例
- 获取产品资料与报价
- 联系销售并明确采购型号

设计要求：参数结构严谨、证据可核验、资料易下载、询盘路径清晰。

### C. 外贸采购客户与海外终端用户

典型需求：

- 使用英文查找准确型号与技术资料
- 获取可转发给海外消费者的产品页面和安装视频
- 了解包装、适配、注意事项与售后联系方式
- 在不同设备和网络环境下稳定访问

设计要求：英文不是机械翻译；产品链接可独立分享；视频应有英文标题、字幕或图示；避免依赖仅在中国大陆可用的平台。

## 4. 核心用户旅程

### 旅程 1：按型号获取安装帮助

`进入网站 → 输入型号 → 打开唯一产品页 → 核对外观/参数 → 观看安装视频 → 查看注意事项 → 查看 FAQ 或联系售后`

### 旅程 2：采购前比较产品

`进入产品中心 → 按类型/用途筛选 → 比较关键参数 → 查看产品详情和工厂能力 → 下载资料/提交询盘`

### 旅程 3：海外客户转发给终端用户

`采购客户复制英文产品链接或二维码 → 消费者打开对应型号页面 → 查看英文安装步骤和视频 → 获取安全与维护说明`

## 5. 首期网站范围

### 必须页面

- 首页
- 产品中心
- 产品分类页
- 独立产品详情页
- 安装与使用支持中心
- 独立教程/视频页或可深链的视频区块
- 公司与工厂
- 资质与专利
- 联系我们
- 中文/英文对应页面

### 产品详情必须包含

- 产品正式名称与型号
- 中文与英文名称
- 主图和细节图
- 适用场景
- 核心特点
- 技术参数及参数单位
- 包装清单
- 安装步骤
- 使用步骤
- 安全注意事项
- 日常维护
- 常见问题
- 安装/使用视频
- 说明书或参数表下载
- 相关配件和适配产品
- 销售/售后联系入口
- 页面更新时间或资料版本

### 暂不作为首期重点

- 在线付款与订单系统
- 用户账户体系
- 经销商复杂权限
- 在线维修工单
- 多语言自动机器翻译

这些功能只有在实际业务流程明确后再评估。

## 6. 内容真实性与证据规则

以下信息可以展示，但必须先取得真实材料，不因“允许展示”而直接编写：

| 内容 | 最低证据 |
| --- | --- |
| 工厂与生产能力 | 原始照片、设备/产线说明、可公开数据 |
| 证书 | 清晰扫描件、证书名称、编号、有效期、适用产品 |
| 专利 | 专利名称、类型、申请/授权号、状态 |
| 客户案例 | 获得公开授权的客户名称或匿名案例资料 |
| 出口地区 | 实际业务记录及允许公开的区域表述 |
| 产品参数 | 已确认的规格表、铭牌或说明书 |
| 安装与注意事项 | 工程/售后人员确认过的步骤与安全文本 |

涉及安全、电气、压力、温度和保修的内容必须由企业负责人或技术人员确认后发布。

## 7. 双语原则

- 中文与英文页面具有相同的信息层级，不把英文版做成简化版。
- 型号、单位、警告语和技术术语建立统一词库。
- 每个产品拥有稳定的语言对应 URL。
- 视频尽量采用无语言依赖的画面步骤，并补充中英文字幕或说明。
- 英文企业名称以营业执照、合同或既有出口资料中的正式写法为准。
- 当前代码使用 `Shanghai Hengmao Machinery`，在取得正式英文名称前仅视为工作名称。

## 8. 主要转化动作

网站主转化不是立即付款，而是完成一次有效的信息获取：

1. 找到正确产品
2. 成功查看安装或使用指导
3. 下载正确资料
4. 携带产品型号联系销售或售后

联系表单或即时通讯入口应自动附带：产品型号、当前语言、页面 URL 和咨询类型。

## 9. 建议成功指标

- 型号搜索成功率
- 产品页到安装视频的点击率
- 安装视频播放/完成率
- 说明书下载量
- 无结果搜索词数量
- 产品页联系转化率
- 中文/英文访问与页面覆盖率
- 移动端产品支持任务完成率

第一阶段不追求虚高访问量，优先验证用户能否正确找到并使用产品资料。
