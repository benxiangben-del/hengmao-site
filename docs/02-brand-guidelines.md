# 上海恒猫机电品牌规范

版本：1.0  
日期：2026-07-17  
状态：已确认

## 1. 品牌核心

上海恒猫机电面向个人消费者、工业采购客户、外贸客户和海外终端用户提供清洁设备、配件及配套的产品支持。

品牌关键词：

- 可靠
- 专业
- 清晰
- 国际
- 耐用

品牌的高级感来自准确的信息、稳定的视觉秩序、真实的产品摄影和克制的交互，而不是装饰性特效。

## 2. 品牌名称

| 场景 | 标准写法 |
| --- | --- |
| 中文正式名称 | 上海恒猫机电 |
| 中文简称 | 恒猫机电 |
| 英文对外名称 | Shanghai Hengmao Machinery |
| 英文字标 | HENGMAO |

规则：

- 中文页面首次出现使用“上海恒猫机电”，后续可使用“恒猫机电”。
- 英文页面公司介绍使用 `Shanghai Hengmao Machinery`。
- Logo、产品铭牌、视频水印和小尺寸场景优先使用 `HENGMAO`。
- 不混用 `Heng Mao`、`HengMao` 或其他大小写形式。

## 3. 品牌口号

- 中文：`可靠设备，清洁更高效`
- 英文：`Reliable Equipment. Cleaner Results.`

口号用于首页品牌区、企业介绍和宣传资料。产品详情页应优先展示产品名称、型号和用途，不能用口号替代具体信息。

## 4. Logo 方向

采用“几何图形标 + HENGMAO 字标”的组合形式。

### 图形概念

- 基础结构来自几何化 `H` 与 `M`。
- 使用一条克制的水流或压力喷射负形体现清洁设备属性。
- 外形紧凑、稳定，避免过度运动感。
- 单色、反白、16–24 px 小尺寸和产品铭牌上均须可识别。

### 禁止方向

- 卡通猫或写实猫头
- 通用复杂齿轮
- 写实水滴
- 多层渐变立体效果
- 细碎线条和难以印刷的高光
- 在 Logo 内加入未经确认的产品参数或企业承诺

在正式绘制 Logo 前，应检索近似商标并确认使用范围。该规范只确定设计方向，不代表商标注册结论。

## 5. 品牌色

### 核心色

| Token | 色值 | 主要用途 |
| --- | --- | --- |
| `brand-600` | `#155EEF` | Logo、主按钮、链接、选中状态 |
| `brand-700` | `#004EEB` | 主按钮悬停、重点操作 |
| `navy-950` | `#0B1220` | 页头、页尾、重点产品展示区 |
| `steel-600` | `#475467` | 次要文字、参数辅助信息 |
| `mist-50` | `#F5F8FF` | 页面浅色背景 |
| `mist-100` | `#EEF4FF` | 信息卡、选中背景 |
| `white` | `#FFFFFF` | 主内容背景 |

### 功能色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `warning-500` | `#F79009` | 注意事项与非危险警告 |
| `danger-600` | `#D92D20` | 安全风险、删除和错误 |
| `success-600` | `#039855` | 成功状态 |

### 使用比例

- 中性白、浅灰：约 70%
- 深海军蓝与文字色：约 20%
- 品牌蓝：约 8%
- 功能色：不超过约 2%，且只表达真实状态

不再把现有荧光绿作为品牌主色。旧视觉可在实施阶段作为对照，不直接删除。

## 6. 字体

### 中文

- 首选：Noto Sans SC / 思源黑体
- 回退：`PingFang SC`, `Microsoft YaHei`, sans-serif

### 英文与数字

- 首选：Inter
- 回退：Arial, sans-serif

### 层级原则

- 页面标题：紧凑、稳定，不使用超细字重
- 正文：保证长说明和移动端阅读
- 型号：字母和数字必须清晰区分
- 参数表：单位与数值对齐，避免全大写长段文字

## 7. 图像与视频

- 产品主图统一角度、背景、光线和留白。
- 产品细节图展示接口、配件、铭牌、操作部件和安装位置。
- 工厂图保留真实环境，可统一裁切与色温，不移除影响真实性的关键内容。
- 安装说明只使用与实际产品一致的照片、视频或技术图。
- 视频应有型号、语言、版本和更新时间。
- 海外用户使用的视频不得只依赖中国大陆限定平台。
- 证书和专利以可阅读资料卡呈现，不作为模糊背景图。

## 8. 语气与文案

### 应该

- 直接说明产品是什么、适用于什么、如何使用
- 使用具体型号、参数和可核验事实
- 安全说明使用明确动作和后果
- 中文自然简洁，英文按英语技术表达重写

### 不应该

- “行业第一”“世界领先”等无证据表述
- 大量空泛词语，如“匠心铸就非凡”
- 用宣传口号替代安装步骤
- 中英文术语、单位和型号不一致
- 隐藏安全限制或适用条件

## 9. UI 表现原则

- 亮色内容区用于参数、教程、FAQ 和长文本。
- 深色区域用于品牌、导航、重点产品和高质量摄影。
- 动画服务于层级和反馈，不影响阅读和操作。
- 安装步骤、警告和下载入口在移动端保持明显。
- 控件状态至少包含默认、悬停、键盘焦点、禁用、加载、成功和错误。

## 10. 后续交付物

- Logo 主标、横版组合和图形标
- 单色与反白版本
- SVG、PDF、PNG 和 favicon
- 最小尺寸与安全区域图
- 产品铭牌、视频水印和网页应用示例

Logo 资产将在信息架构和设计系统确认后单独制作，避免视觉先于使用场景。

## 11. 验收标准

- 中文、英文和小尺寸场景的名称一致。
- 主色满足网页文字与控件的可读性要求。
- Logo 在网页、铭牌、包装和单色印刷中可使用。
- 摄影与视频不误导产品型号或安装方式。
- 文案不包含无证据的性能或领先性承诺。
