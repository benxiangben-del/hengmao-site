# 上海恒猫机电官网组件规范

版本：0.1  
日期：2026-07-17  
状态：已确认；组件细节将在线框与样稿阶段验证

## 1. 组件分层

```text
基础组件
├── Button / Link
├── Input / Select / Checkbox
├── Badge / Alert
├── Icon / Divider / Skeleton
└── Dialog / Drawer

复合组件
├── Header / MobileNav / Footer
├── SearchBox / LanguageSwitcher
├── ProductCard / ProductGallery
├── SpecificationTable
├── InstructionSteps / SafetyNotice
├── VideoPlayer / DownloadCard
└── ContactPanel / EvidenceCard

页面模块
├── HomeHero / ProductCategoryGrid
├── ProductOverview / ProductSupport
├── SupportSearch / GuideListing
├── FactorySection / CredentialsGrid
└── ContactForm
```

基础组件不包含产品业务；业务组件不重复实现按钮、输入框和提示框。

## 2. 全局页头 Header

### 内容

- HENGMAO Logo
- 一级导航
- 型号搜索入口
- 中文/英文切换
- 移动端菜单

### 行为

- 首页可在 Hero 上方使用透明/深色状态，滚动后变为稳定背景。
- 内页使用固定清晰背景。
- 当前页面有明确选中状态。
- 语言切换保留当前页面上下文。
- 移动端菜单打开后锁定背景滚动并正确管理焦点。

### 验收

- 键盘可以完整操作。
- 320 px 宽度下 Logo、搜索、语言和菜单不重叠。
- 不依赖 hover 才能打开关键导航。

## 3. 型号搜索 SearchBox

### 变体

- 首页大型搜索
- 页头紧凑搜索
- 产品/支持列表搜索

### 内容

- 明确标签或可访问名称
- 示例型号占位提示
- 搜索按钮
- 清空按钮
- 加载、无结果、错误状态

### 行为

- 忽略型号中的大小写、空格、连字符差异。
- 完整型号优先直达产品页。
- 多个结果进入搜索结果页。
- 无结果时提供产品中心、联系支持和重新搜索入口。

## 4. 产品卡 ProductCard

### 必须字段

- 产品主图
- 产品名称
- 型号
- 产品类别
- 1–3 个关键参数
- “查看产品”操作

### 变体

- 标准列表卡
- 首页重点产品卡
- 相关产品紧凑卡

### 规则

- 整张卡可以点击，但内部链接语义必须清晰。
- 图片使用统一比例，不裁切关键部件。
- 型号位置保持一致。
- 不在卡片中堆积完整介绍。
- 缺图时使用中性占位并显示产品名称。

## 5. 产品图片 ProductGallery

### 内容

- 主图
- 缩略图
- 前后切换
- 放大查看
- 图片说明

### 行为

- 支持触摸滑动和键盘操作。
- 切换图片不造成页面明显跳动。
- 放大图保持关闭按钮、焦点圈和 Escape 退出。
- 图片替代文本说明角度或部件，而不是重复“产品图片”。

## 6. 产品概览 ProductOverview

首屏组合：

```text
面包屑
产品图库 | 类别 / 产品名称 / 型号
         | 简短用途说明
         | 3–5 个关键参数
         | 安装视频 / 下载说明书 / 联系咨询
```

移动端顺序：面包屑 → 名称型号 → 主图 → 关键参数 → 快捷操作。

## 7. 参数表 SpecificationTable

### 数据规则

- 参数名称、值和单位分离存储。
- 同一参数使用统一名称与单位。
- 未提供值显示“—”，不显示虚构默认值。
- 可增加资料版本或更新时间。

### 展示

- 桌面端使用清晰两列或分组表格。
- 移动端转换为标签/值行，不缩小到难以阅读。
- 长单位和英文名称允许换行。
- 支持复制型号和关键参数。

## 8. 安装步骤 InstructionSteps

### 每步包含

- 步骤编号
- 动作标题
- 简短说明
- 对应图片或视频时间点（可选）
- 所需工具/配件（可选）
- 注意或警告（可选）

### 规则

- 一步只描述一个主要动作。
- 顺序不可跳跃。
- 通用步骤与型号专属步骤明确标识。
- 技术人员审核后才能发布。

## 9. 安全提示 SafetyNotice

### 等级

- 信息：补充说明
- 注意：可能造成使用失败或轻微损坏
- 警告：可能造成设备损坏或人身风险
- 危险：存在严重风险，仅在技术资料明确支持时使用

### 结构

- 图标
- 等级标题
- 明确风险
- 应采取的动作
- 禁止动作（如适用）

安全提示不能折叠为默认不可见，也不能只用颜色表达等级。

## 10. 视频播放器 VideoPlayer

### 元数据

- 视频标题
- 适用型号
- 内容类型：安装/使用/维护
- 语言和字幕
- 时长
- 版本/更新时间
- 海报图

### 行为

- 不自动播放声音。
- 支持字幕、全屏和键盘控制。
- 视频不可用时提供文字步骤与下载资料。
- 可从产品页复制直达视频区块的链接。

## 11. 下载卡 DownloadCard

显示：

- 文件名称
- 适用型号
- 语言
- 版本或日期
- 文件类型与大小
- 下载按钮

旧版资料不能静默覆盖；更新时保留版本和重定向策略。

## 12. FAQ

- 问题标题必须可独立理解。
- 答案短而直接，复杂问题链接到完整指南。
- 折叠组件支持键盘和屏幕阅读器。
- FAQ 按产品或主题关联，不把所有问题放在一个长列表中。

## 13. 企业证据卡 EvidenceCard

用于工厂、证书、专利和案例。

### 证书/专利字段

- 名称
- 编号
- 颁发/授权机构
- 有效期或状态
- 适用产品
- 可公开的预览或验证信息

### 规则

- 不用模糊 Logo 墙代替证据。
- 客户名称必须获得公开授权；否则采用真实但匿名的案例结构。
- 过期证书明确标注或下线。

## 14. 联系面板 ContactPanel

产品页联系入口自动携带：

- 产品名称与型号
- 当前语言
- 当前页面 URL
- 咨询类型

按钮可包含“咨询产品”“安装帮助”“售后支持”，避免所有场景只显示“联系我们”。

## 15. 状态组件

每个数据型组件必须定义：

- 初始状态
- 加载骨架
- 空状态
- 部分数据状态
- 错误状态
- 重试操作
- 离线或媒体不可用状态（适用时）

不能把 Supabase 或环境变量错误直接暴露给普通访客；前台显示友好说明，详细错误仅记录在安全的诊断环境。

## 18. 实施时预计修改的文件

- 新增 `src/ui/` 基础组件
- 新增 `src/components/` 复合组件
- 新增 `src/features/products/` 与 `src/features/support/`
- 从 `src/App.jsx` 逐步迁移现有产品卡、导航、搜索和详情模块
- 从 `src/App.css` 逐步迁移组件样式
- 后台复用相同基础控件，但保持管理界面与前台业务组件隔离

## 19. 验收标准

- 每个核心组件拥有明确字段、变体、状态和移动端行为。
- 同一操作不出现多套无意义的按钮样式。
- 产品页首屏能识别名称、型号、关键参数和支持入口。
- 安装步骤与安全提示无需依赖视频也能理解。
- 视频或图片失败不会阻断产品资料访问。
- 组件可以在中文和英文长文本下正常布局。
- 所有交互组件支持键盘操作和清晰焦点。
