# 上海恒猫机电官网 SEO 规范

版本：0.1  
日期：2026-07-17  
状态：待域名与上线环境确认

## 1. SEO 目标

SEO 首先帮助用户通过品牌、产品名称和型号找到正确页面，其次覆盖产品类别、安装和使用问题。

优先搜索意图：

1. `品牌 + 产品型号`
2. `产品型号 + 安装/说明书/使用方法`
3. `产品类别 + 关键用途或参数`
4. `品牌 + 公司/工厂/证书`

不以堆砌大量泛化关键词为目标。

## 2. 技术渲染要求

- 每个公开页面拥有真实、稳定 URL。
- 搜索引擎和关闭 JavaScript 的基础抓取环境应能获得页面标题、描述和主要正文。
- 产品与支持页面采用构建时预渲染、服务端渲染或同等可索引方案。
- 实施时优先保留现有 React/Vite 项目，通过小规模原型验证方案，不直接全栈迁移。
- 后台、预览和草稿页面禁止索引。

是否采用具体预渲染工具，在实施前依据当时官方维护状态和部署环境单独验证。

## 3. URL 与语言

示例：

```text
https://example.com/zh/products/hm-p1200-portable-washer/
https://example.com/en/products/hm-p1200-portable-washer/
```

规则：

- 中文使用 `/zh/`，英文使用 `/en/`。
- slug 使用小写 ASCII 与连字符。
- 同一产品的中英文页面使用相同产品 slug。
- 每页输出自引用 canonical。
- 每组双语页面输出 `hreflang="zh-CN"`、`hreflang="en"` 与适当的 `x-default`。
- 不使用查询参数作为正式产品 URL。
- URL 修改时配置 301 永久重定向。

## 4. 页面元数据

### 标题模板

| 页面 | 中文示例 | 英文示例 |
| --- | --- | --- |
| 首页 | 上海恒猫机电｜洗车机与清洁配件 | HENGMAO | Car Washers & Cleaning Accessories |
| 产品 | `{产品名} {型号}｜参数、安装与使用` | `{Product} {Model} | Specs, Installation & Use` |
| 分类 | `{分类名称}｜上海恒猫机电` | `{Category} | HENGMAO` |
| 指南 | `{型号} {指南主题}｜恒猫产品支持` | `{Model} {Guide Topic} | HENGMAO Support` |

每页必须具有独立 title 和 description。description 描述页面能帮助用户完成什么，不堆关键词。

## 5. 页面正文要求

### 产品页

- 唯一 H1：产品名称与型号
- 首屏出现型号和核心用途
- 参数、安装、使用、安全和下载使用清晰 H2/H3
- 图片替代文本描述产品或部件
- 视频提供标题、说明和文字替代内容
- 标注资料版本或更新时间

### 支持指南

- 标题包含适用型号与任务
- 步骤以结构化有序列表呈现
- 警告语出现在相关步骤附近
- 提供返回产品页和相关指南的内部链接

## 6. 结构化数据

根据页面真实内容选择：

- `Organization`：公司基本信息
- `WebSite`：站点与搜索入口
- `BreadcrumbList`：面包屑
- `Product`：产品名称、型号、品牌、图片和描述
- `VideoObject`：安装/使用视频
- `HowTo`：满足规范且步骤完整的安装/使用指南
- `FAQPage`：页面中真实可见的 FAQ

没有公开价格、库存或评价时，不为 Product 虚构 `offers`、评分或评论。

## 7. 社交分享

每个产品与指南页面配置：

- Open Graph 标题、描述、图片、URL 和语言
- Twitter/X 卡片基础信息
- 1200 × 630 px 分享图或可自动生成的产品模板
- 产品型号在分享图中清晰可见

## 8. Sitemap 与 Robots

- 自动生成公开中文、英文页面 sitemap。
- 只包含 `published` 页面和 canonical URL。
- 产品归档后从 sitemap 移除，但旧 URL 根据业务情况保留说明或重定向。
- `robots.txt` 指向 sitemap。
- `/admin`、预览、草稿、内部搜索参数页和测试环境禁止索引。
- 预览环境通过响应头或站点级设置阻止索引，而不只依赖 robots。

## 9. 内部链接

- 首页链接到主要分类、重点产品和支持入口。
- 分类页链接到每个产品。
- 产品页链接到安装指南、说明书、配件和相关产品。
- 指南页链接回对应产品。
- 公司证据页链接到适用产品或产品类别。
- 面包屑反映真实层级。

## 10. 图片与视频 SEO

- 文件名包含产品型号和视角/用途，不使用随机中文文件名作为公开名称。
- 图片使用合适尺寸、格式和压缩。
- alt 描述图中可见信息，不堆关键词。
- 视频提供海报、字幕或文字步骤。
- VideoObject 中的日期、时长、缩略图和内容 URL 必须真实。

## 11. 性能与体验指标

正式验收目标以移动端为主：

- Core Web Vitals 达到良好区间作为目标
- 首屏产品图尺寸明确，避免布局跳动
- 主内容与交互不被大型脚本阻塞
- 第三方视频采用延迟加载或点击后加载
- 404、加载失败和无结果页面仍提供有效导航

具体数值在实施和真实部署后记录，不在没有测量前承诺固定分数。

## 12. 内容质量

- 产品信息由企业真实资料支持。
- 同型号信息避免拆成大量重复薄页面。
- 中英文分别人工审核。
- 安装和安全内容由技术人员审核。
- 证书、专利和案例页面包含真实细节，而非只有图片。
- 页面更新时保留资料版本和更新时间。

## 13. 分析与隐私

建议记录：

- 型号搜索和无结果搜索词
- 产品页到视频、下载和联系入口的点击
- 中英文页面使用情况
- 404 页面来源

上线分析工具前应确定适用的隐私政策、Cookie 策略和数据保留范围。联系表单不得收集与业务无关的敏感信息。

## 14. 上线检查

- 域名 HTTPS 正常
- www/非 www 与尾斜杠策略统一
- canonical 使用正式域名
- 中文/英文 hreflang 成对存在
- sitemap 与 robots 可访问
- 404 返回正确状态
- 产品分享图和结构化数据可验证
- 后台与预览环境不可索引
- 没有占位电话、邮箱、虚构价格或测试产品

## 15. 验收标准

- 每个产品和指南拥有独立可索引 URL。
- 页面源内容包含有效标题、描述和主要正文。
- 双语页面 canonical 与 hreflang 正确。
- 产品结构化数据不包含虚构字段。
- sitemap 只包含已发布页面。
- 型号搜索与内部链接形成清晰发现路径。
