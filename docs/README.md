## 决策优先级

发生冲突时按以下顺序处理：

1. 用户最新明确要求
2. 真实企业与产品资料
3. 产品规范和信息架构
4. 安全、可访问性和 SEO 规范
5. 品牌、设计系统和组件规范
6. 现有实现细节

不能为了保留旧代码而违反已确认的用户任务和安全要求，也不能为了视觉效果虚构企业或产品信息。

## 实施规则

- 每个阶段开始前说明目标、关键决策、预计修改文件和验收标准。
- 先复用和迁移真实内容，再删除旧实现。
- 每个阶段保持可构建、可预览、可回滚。
- 任何数据库生产迁移前必须备份并验证 RLS。
- 产品参数、安装步骤和安全警告必须由企业指定人员审核。
